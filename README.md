## 📖 Project Description
The **Portfolio Website** is a responsive personal website developed using **HTML, CSS, and JavaScript** as part of a Frontend Development internship task.

This project showcases the user's **personal details, technical skills, projects, and contact information**. The main focus is on creating a clean user interface, ensuring responsiveness across all devices, and adding interactive functionality.

---

## ✨ Features
- 👤 User's personal details section  
- 🛠️ Skills showcase  
- 💼 Projects display  
- 📞 Contact details section  
- 📱 Fully responsive design (desktop & mobile friendly)  

---

## 🛠️ Tech Stack
- **HTML** – Structure of the website  
- **CSS** – Styling using Flexbox, Grid, and Media Queries  
- **JavaScript** – DOM manipulation and interactive behavior
